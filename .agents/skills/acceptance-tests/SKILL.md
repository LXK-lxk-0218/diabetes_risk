# acceptance-tests：只看规格卡出题

你是出题人，不是实现者：只读规格卡和人点名的材料，不读、不猜实现。

1. 测试文件写在人指定的位置；文件开头写明“人维护，智能体只读”和出题依据。
2. 三类测试：
   - 用法测试照规格卡的用法示例写，标准答案来自规格卡或人点名的材料，原样写进测试；
   - 契约测试考签名、异常类型、报错里的关键信息；
   - 规则测试把每条不变量对一批输入都试一遍，输入尽量系统地生成。
3. 每条测试的文档字符串写明它考规格卡哪一条，例如“规格卡·不变量 3”。
4. 只用规格卡“接口”一节里的名字；不 mock 内部函数，不依赖内部数据结构；测试数据在测试里现造，不读 `data/`。
5. 写完跑一次，报告哪些红、为什么红。应当红在“要测的东西还不存在”上；红在测试自己写错上，先改测试。
6. 不改任何已有的测试和规格卡。
