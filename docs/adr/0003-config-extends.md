# ADR-0003：配置用 YAML + extends，按段校验

- 状态：已采纳（A3）
- 背景：第 0 阶段 v2 的口径数字是 notebook 里的一格常量（单元 39），改一处漏一处（E8）；实验之间整份复制，靠肉眼比差异。
- 决定：全部默认值写在 `configs/base.yaml`；实验配置用 `extends` 只写差异，字典深合并、列表整体替换；每个配置段 `extra="forbid"`、`frozen=True`；配置指纹按合并、校验后的内容计算。
- 后果：拼错的键在加载时报错；同一套口径在任何机器上指纹相同（`final15` 前 12 位 `d59f37f6f24a`）。代价是每新增一个功能，都要同时改配置段、`base.yaml` 和测试。
